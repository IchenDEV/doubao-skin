# Intent: 在“关于豆皮”中增加开源与官方免费声明

## Problem

当前 macOS 原生“关于豆皮”面板只展示应用身份、版本与版权，用户无法在面板内核验官方源码仓库，也无法得知官方发行版永久免费。Windows 桌面应用则没有“关于”入口。第三方若冒充官方渠道收费，两个平台的用户都缺少就近、可信的识别提示。

## Proposed outcome

macOS 继续使用原生关于面板，在现有信息下方加入可点击的官方 GitHub 仓库链接和简短声明。Windows 在主窗口标题栏右侧增加低干扰的“关于”文字入口，点击后打开轻量应用内模态窗，展示应用名、版本、同一 GitHub 链接和同一声明：“本软件开源，官方版本永久免费。如遇冒充官方收费，请勿购买，请从 GitHub 官方仓库核验并下载。”

声明不使用“任何收费即为盗版”的绝对表述，因为项目采用 MIT License，该许可证允许他人复制、分发、再许可或出售副本；产品应警示“冒充官方收费”，而不是否定许可证已经授予的权利。

## Affected users and systems

- 使用 macOS 与 Windows 桌面应用“豆皮”的用户。
- `apps/desktop` 中的 AppKit 原生关于面板、Windows 标题栏入口、轻量模态窗、中文文案与回归测试。
- 官方仓库 `https://github.com/IchenDEV/doubao-skin`；不改变网站、主题包或发布流程。

## Constraints

- 保留现有 macOS 原生关于面板，不新建自绘窗口、设置页或网页。
- Windows 没有原生应用菜单；只在现有标题栏右侧增加“关于”文字入口，不新增完整菜单、设置页或导航项。
- Windows 关于模态窗复用现有 GPUI、颜色与排版能力，不引入新的窗口、菜单或 UI 依赖。
- GitHub 链接必须可点击，并交由系统默认浏览器打开；显示完整可信域名，避免模糊跳转。
- 声明必须明确“开源”和“官方版本永久免费”，并把风险限定为“冒充官方收费”。
- 不将“所有收费均为盗版”写入产品，因为这与仓库 MIT License 允许出售副本的条款冲突。
- 不增加网络请求、遥测、更新检查或后台仓库访问；只有用户主动点击链接时才离开应用。
- 保留现有应用名称、图标、版本、构建号、版权、标准菜单和快捷键行为。

## Out of scope

- 修改 MIT License、项目授权范围或第三方主题素材许可证。
- 增加捐赠、购买、举报、自动验真或反盗版系统。
- 为 Windows 新增独立页面、系统托盘菜单或多层设置导航。
- 重构主窗口、菜单结构、主题功能或网站导航。

## Success signals

- macOS 从应用菜单打开“关于豆皮”后能看到官方 GitHub 仓库链接和开源/官方免费声明。
- Windows 标题栏右侧存在低干扰的“关于”入口，打开后能看到应用名、当前版本、同一链接和声明；关闭后主界面状态不变。
- 点击链接只打开 `https://github.com/IchenDEV/doubao-skin`，不触发其他网络行为。
- VoiceOver 与 Windows 辅助功能能够读取入口、完整声明、链接和关闭操作。
- 现有图标、名称、版本、构建号、版权及关于面板单实例行为保持不变。
- 定向测试、Rust 检查、workflow 检查和真实打包应用的正常/窄屏窗口验证通过，并在 `verification.md` 留下证据。

## Open questions

请产品负责人确认是否接受上述法律上更准确的文案和 Windows 标题栏入口方案。若必须逐字使用“如有发现收费，即为盗版”，需要先变更许可证或取得法律确认，本变更不会自行写入该绝对判断。

## Decision

上一版仅覆盖 macOS 的意图已因用户补充 Windows 要求而撤回。等待产品负责人明确接受当前跨平台意图后再进入规格设计；本阶段不修改产品代码。
